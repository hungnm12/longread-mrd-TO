Compared the published MRD methods along one grid — signal used, problem solved, position in a detector, shared idea, unique idea, limitation — and surveyed what this server actually offers. Then parked the direction that combined SNV candidates with haplotype phase and native methylation: it is one idea at one position, and the project needs its full problem set written down first.

Focus

How do the supplied methods differ in signal, position and limitation, and where could a native long-read platform add something?

What was done

  • Paused the site and research-OS implementation stream; no further site features are being added for now
    • Showed: The site and its record store are complete and deployed, so pausing leaves no half-finished route.
  • Surveyed the server and wrote the knowledge base — ONT capabilities, datasets, tools, constraints, method synthesis, open questions
    • Showed: Every sampled read carries 5mC and 5hmC and none carries HP/PS; the dilution series holds 14 BAMs (5 blanks, 3 replicates per level) rather than one per level; the BAM header records no basecaller or read group; ClairS-TO’s wrapper does not start because python is absent from PATH; there is no GPU on this host.
  • Built a seven-dimension comparison matrix over the supplied literature
    • Showed: Every method makes each molecule count for more before aggregating — more loci, a learned prior, a second linked variant, a consensus, or a second signal class. The differences sit in which of those five, not in the overall strategy.

What the output showed

  • The dilution series has 3 replicates per tumor-bearing level and 5 blanks, which contradicts the research contract’s “1 replicate” assumption and its conclusion that no limit-of-blank estimate is possible.
  • Native 5mC and 5hmC are present on every sampled read of both the pure tumor BAM and the 0.01% dilution; HP and PS are absent everywhere, so phasing is unstarted work rather than missing data.
  • Background suppression is the least crowded position in the matrix: PhasED-Seq by linkage and MRD-EDGE by learned ranking, both under constraints that do not hold in a tumor-only long-read setting.
  • PhasED-Seq’s requirement of two somatic variants on one fragment becomes least satisfiable exactly at the tumor fractions that matter.
  • NanoRCS raises per-read accuracy through amplification-based consensus, which is the opposite trade from keeping the molecule native for methylation.

What I take it to mean

The matrix supports the framing already recorded rather than changing it: the open position is per-molecule background suppression using evidence that is native to the molecule. It also sharpens one contrast worth keeping — accuracy through amplification and modality through native sequencing are competing designs, not complementary ones.

What did not work

  • No row in the matrix is backed by a source PDF; all entries derive from indexed summaries
    • Impact: The matrix cannot yet be cited as thesis evidence
    • Handling: Marked unverified in the document header, with the inferred entries flagged individually
  • Whether rolling-circle consensus preserves native base modifications is an inference, not a checked fact
    • Impact: One limitation cell may be wrong
    • Handling: Flagged in the document as [unverified] pending the source PDF

Decisions

  • Pause the website and research-OS implementation stream — The site, record store and reporting tooling are complete and deployed; further work there does not advance the research question
  • Treat the signal matrix as the working comparison for method positioning — It states each method’s position and limitation in the terms this project needs, rather than paper by paper
  • Park the SNV + haplotype phase + native methylation direction and clear it from the active state — Removing the matrix row was not enough — the direction still occupied the scope contract, the hypotheses, the dashboard question and the orchestration state, so every question asked kept forming around it. Its documents moved intact to research/parked/snv-phase-methylation/ with resume conditions; the descriptive candidate landscape and the environment survey stand on their own.
  • Remove this project’s own row from the signal matrix and leave its placement pending — A single row framed the project as one idea at one grid cell — per-molecule background suppression for the single-variant tumor-only case. The project is expected to address several of the problems in the table at once, so placing one row now would fix the wrong shape before the broader scope is written.
