# Benchmark Protocol

## 1. Benchmark identity

```yaml

version: 0.1

created_from:

  - research/findings/FIND-0021.md                          # oracle-free per-read methylation
  - research/surveys/long-read-tumor-only-mrd/exp-s1-022/   # D1-D4, HCC1395 only
  - research/THESIS-PLAN.md

```

## 2. Research question

```text
Does adding an oracle-free per-read methylation filter to the frozen SNV-only
gated detection score improve sample-level detection of tumour-derived DNA
in ONT tumour/normal dilution samples at 1%, 0.1% and 0.01% tumour fraction,
relative to the SNV-only score alone,
and does any improvement replicate on a second individual?
```

The vague form "does methylation help" is not what is measured. What is measured is a change
in one preregistered scalar, on the same samples, same candidates, same gate, same call rule,
with exactly one difference: which ALT reads are counted.

## 3. Hypotheses

### H0
Adding the per-read methylation filter does not increase the primary metric
(minimum-over-replicates interval-lower-bound z at 0.1%) relative to SNV-only,
on either individual; or any increase it produces is matched by a
retention-rate-matched random filter or by a methylation-shuffled filter.

### H1
Adding the per-read methylation filter increases the primary metric relative to
SNV-only on both individuals, by more than a retention-rate-matched random filter
and more than a methylation-shuffled filter.

## 4. Prediction task

**Sample-level cancer detection.** For one sequencing sample, emit a detection call
(`detected` / `UNRELIABLE` / `not detected`) for the presence of tumour-derived DNA,
using only the sample under test, that individual's frozen tumour-only candidate set,
and that individual's tumour-free blank samples.

This is not variant classification, not read classification, and not tumour-fraction
estimation. Read classification was measured separately (FIND-0021) and does not
license an MRD claim.

## 5. Unit of analysis

```yaml
unit_of_analysis: sample
```

One evaluated observation is one dilution BAM. This matches the research question,
which asks about detection of a *sample* as tumour-bearing, and it matches the unit
fixed by `research/decisions/2026-08-25-metric-and-baseline.md`, which this benchmark
does not change.

Replicates within a level are three separate BAMs and are treated as three observations,
with the explicit caveat in section 17 that they are pseudo-replicates.

The executor must copy both frames verbatim to `results/candidate_universe.tsv` and record
their SHA-256.

## 9. Baseline

```yaml
baseline_id: B0
name: frozen gated detection score (SNV-only)
inputs:
  - candidate set (tumour-only, no matched normal)
  - the sample under test
excluded: [methylation, phasing, CNV, matched normal, truth labels, population panels]
prediction_target: sample-level detection call
```

Definition, unchanged from `research/decisions/2026-08-25-metric-and-baseline.md`:

```text
alt_reads(c,s) = reads at candidate c in sample s carrying the ALT allele,
                 base quality >= 20, mapping quality >= 20
G(s)           = sum over candidates c of alt_reads(c,s)  where 1 <= alt_reads(c,s) <= 2
z(s)           = ( G(s) - mean_blank ) / sd_blank
call           = detected if z >= 3
```

This is the reference comparator because it is the project's frozen metric: it is already
measured on both individuals, it is the thing a methylation channel must beat to be worth
anything, and it differs from every treatment arm in exactly one respect.

## 10. Treatment arms

All arms share: the same BAM pass, the same candidate universe, the same quality thresholds,
the same gate `1 <= alt <= 2`, the same blank construction, the same call rule. They differ
only in **which of the gate-passing ALT reads are counted**.

| arm | name | counted ALT reads |
|---|---|---|
| B0 | SNV-only (baseline) | all of them |
| B1 | SNV + per-read methylation | only those whose methylation-disagreement score `d > cut` |
| C1 | retention-matched random control | a uniformly random subset of the same size as B1's, per sample |
| C2 | methylation-shuffled control | as B1, after permuting per-read methylation call vectors across reads |

C1 and C2 are **preregistered controls, not exploratory extras**. They are part of the primary
decision rule (section 20). Their purpose:

- **C1** separates "methylation chooses the informative reads" from "any filter that shrinks
  the blank raises z". Because `z = (G - mean_blank)/sd_blank` and the blank shrinks under any
  filter, a retention-rate-matched random filter is the arm that must be beaten.
- **C2** separates the methylation *signal* from the *architecture* of the filter (consensus,
  confident-position selection, 95th-percentile cutoff). If C2 matches B1, the pipeline is
  producing the effect and the modification calls are not.

### B1 definition (oracle-free, fixed a priori)

Every parameter below is carried unchanged from EXP-S1-022 step 5 and is frozen here.
None is fitted, tuned or selected in this benchmark.

```text
ML          = 128/255      modification-probability threshold for calling a CpG methylated
MIN_COV     = 10           minimum observations at a reference position to enter the consensus
CONF_BAND   = rate < 0.1 or rate > 0.9    a position is "confident"
MIN_CPG     = 5            minimum confident positions on a read for it to be scorable
PCT         = 95           percentile of the background score distribution used as the cutoff
```

Procedure, per sample, using only that sample:

1. Pile up every candidate; record depth, and the read names carrying ALT.
2. For every read touched in step 1, record its per-reference-position methylation calls.
3. Build a consensus methylation rate at every reference position seen with >= MIN_COV
   observations, **from exactly those reads** — so the positions scored and the positions
   defining confidence are the same set by construction.
4. Keep the confident positions.
5. Score every read: `d = (disagreements with consensus) / (confident positions on the read)`,
   defined only if the read carries >= MIN_CPG confident positions; otherwise `d = missing`.
6. `cut` = the PCT-th percentile of `d` over all scorable reads in this sample.
7. An ALT read is **kept** if `d` is defined and `d > cut`.

The matched normal is never opened. No reference methylome, tissue atlas or between-tissue
comparison is used — the project's only matched normal is evaluation-only, so the substitute
is confidence within one sample. This is weaker in principle and is stated as such.

### C1 definition
For each sample, let `k` = the number of ALT reads B1 kept at gate-passing candidates and
`n` = the number of scorable ALT reads B1 could have kept. Draw `k` of those `n` uniformly at
random, seed `20260831` combined with the sample id (recorded in `random_seeds.yaml`).
Repeat 200 times; C1's statistic is the **mean** over draws, and its spread is recorded.

### C2 definition
Permute the per-read lists of methylation calls across the reads of the sample (seed as above),
then run steps 3-7 of B1 unchanged. Repeat 20 times; C2's statistic is the mean over permutations.

## 11. Features and evidence provenance

| Evidence | Source | Used by | Available at inference? | Leakage risk | Missingness |
|---|---|---|---|---|---|
| ALT read count at candidate | BAM pileup of sample under test | B0 B1 C1 C2 | yes | none — no truth involved | none |
| Depth at candidate | same pileup | all (for the plug-in binomial variance, secondary only) | yes | none | none |
| Per-read CpG methylation calls | `MM`/`ML` tags of the sample under test | B1, C2 | yes | none — sample-internal | reads with < MIN_CPG confident positions are unscorable; rate must be reported per arm/level |
| Consensus methylation rate | derived from step 3, sample under test only | B1, C2 | yes | **none by construction** — built from the test sample itself, no reference tissue, no matched normal | positions with < MIN_COV observations are excluded |
| Confident-position set | derived, sample under test only | B1, C2 | yes | none | — |
| Cutoff `cut` | 95th percentile of that sample's own background scores | B1, C2 | yes | none — not selected against any outcome | — |
| Candidate coordinates | frozen tables, drawn with recorded seeds before this benchmark | all arms | yes | none — identical across arms | — |
| Nominal tumour fraction | directory provenance | **evaluation only** | n/a | would be leakage if used in scoring; it is not | — |

No feature encodes the truth label. No arm receives the matched normal, SEQC2, a panel of
normals, or any population database.

## 12. Experimental controls

- **Coverage.** All arms read the same BAM in the same pass and see identical depth. No arm
  receives more reads. Depth is recorded per candidate per sample so this is auditable.
- **Candidate selection.** Frozen, identical across arms, recomputed from nothing. Gate applied
  identically. Only the ALT-read subset differs.
- **Missing evidence.** Unscorable ALT reads are dropped by B1. If unscorability rate differs
  between blank and dilution, missingness itself could carry the label; the executor must report
  the rate per arm and level (section 22) and C1 matches B1's retention rate exactly, so the
  shrinkage component is controlled.
- **Retention rate.** C1 exists solely for this confounder.
- **Filter architecture.** C2 exists solely for this confounder.
- **Dilution.** All three levels are evaluated separately and all three are reported, including
  0.01%, which prior work found undetectable in every configuration. It may not be dropped.
- **Genomic context.** HCC1395's frame is chr1 only, COLO829's is genome-wide; this is a
  between-individual difference, and no criterion compares individuals numerically.
- **Model complexity.** No model is fitted in any arm. B1 has no free parameter that B0 lacks —
  all five constants are fixed a priori from a prior experiment.
- **Class imbalance.** Not applicable at the sample level: 3 negatives and 9 positives per
  individual, all reported.

## 13. Data splitting

No train/test split exists, because nothing is trained. Every parameter is fixed a priori.
The split manifest records, for each sample: individual, level, replicate, role
(blank-reference or evaluated), and the fact that no sample contributes to any fitted quantity.

The blank reference for individual *i* is the mean over that individual's TF0 rep1-3.
A blank replicate is never scored against itself alone.

## 14. Leakage guards

| path | guard |
|---|---|
| truth set used as a feature | SEQC2 / orthogonal VCFs are not opened by any arm; executor must record that no such file was read |
| matched normal used in discovery or inference | HCC1395BL / COLO829BL BAMs are not opened; executor must record this |
| labels used during candidate generation | candidate frames were drawn before this benchmark, with recorded seeds, from PASS calls only |
| threshold selection using the evaluated data | all five methylation constants, the gate bounds and z >= 3 are carried unchanged from prior frozen records; none is re-selected here |
| normalisation fitted on the full dataset | the consensus, confident set and cutoff are fitted **per sample, on that sample alone**; nothing is pooled across samples |
| cross-sample leakage | each sample's methylation model is built independently; sample ids never mix |
| blank leakage | blank reference and evaluated sample are always distinct BAMs |
| results-driven redesign | this protocol is locked before execution and its checksum recorded |

## 15. Primary metric

```yaml
primary_metric: zlo_min_0.1%
```

Definition, per individual per arm:

```text
For each of the three 0.1% replicates r:
    z(r)    = ( G_arm(r) - mean_blank_arm ) / sd_blank_arm
    zlo(r)  = lower end of the 95% interval on z(r) obtained by propagating the
              Student-t 95% interval on mean_blank_arm (3 blank replicates, 2 df)
zlo_min = min over the three replicates of zlo(r)
```

`mean_blank_arm` and `sd_blank_arm` are the mean and standard deviation of that arm's gated
statistic over that individual's TF0 rep1-3. This is the reporting procedure fixed in
`§4c` of the metric decision; it is applied identically to all four arms.

**Why this level.** 0.1% is the only level at which the arms can separate, and that was
established before this benchmark on prior evidence, not on its results: 1% detects in every
arm, individual and variance model measured to date, and 0.01% is 0/3 everywhere and was shown
in FIND-0019/EV-0039 to be signal-limited rather than background-limited, so no filtering
change can reach it. Selecting 0.1% after seeing these results would be goalpost-moving;
selecting it from the frozen prior record is not.

**Why the lower bound.** The point z at 0.1% has already been shown to be unstable enough that
the blank replicates alone move it across the call threshold (§4c). A criterion on the point
estimate would be a criterion on noise.

## 16. Secondary metrics

Preregistered, reported for every arm, individual, level and replicate:

- point z (frozen construction, Poisson blank sd and plug-in-binomial sd both reported)
- interval z and the three-way verdict `detected` / `UNRELIABLE` / `not detected`
- level detection under the frozen replicate rule (a level detects only if all 3 replicates do)
- gated statistic `G` itself
- ALT-read retention rate, per level
- unscorable-ALT fraction, per level
- number of gate-passing candidates, per level

## 17. Statistical analysis

```yaml
comparison: B1 - B0 in the primary metric, within individual; and B1 - C1, B1 - C2
null_hypothesis: the differences are <= 0
statistical_test: NONE — see justification
confidence_interval: Student-t 95% on the blank mean, propagated onto z (2 df)
multiple_testing_correction: not applicable — one primary comparison per individual, both reported
effect_size: the paired difference in zlo_min, in z units, reported per individual with the
             per-replicate paired differences that produced it
```

**Justification for running no significance test.** The three replicates at a level are
subsamples of one library, not independent samples. FIND-0018 / EV-0038 measured the
consequence directly: the pseudo-blank spread understates the between-library spread of the
ungated statistic by more than an order of magnitude. A t-test on n=3 pseudo-replicates would
produce a p-value whose denominator is known to be wrong in the permissive direction. The
benchmark therefore decides on a preregistered **consistency rule** over paired differences
(section 20) plus interval reporting, and reports effect sizes. No p-value is computed, so
none can be selected after the fact.

Both arms are computed on the same BAM in the same pass, so every comparison is paired at the
sample level and the pseudo-replication affects both arms identically.

## 18. Ablation plan

The ablation is the four arms of section 10, which isolate three separable things:

```text
B0              SNV evidence only
B1  - B0        what adding the methylation filter does
B1  - C1        what methylation adds over any equally aggressive filter
B1  - C2        what the modification calls add over the filter's architecture
```

Phasing and CNV arms are **out of scope**: HP/PS tags are absent from all BAMs (verified
2026-08-19) and no CNV calls exist. They are not silently omitted; they are unavailable.

## 19. Low-signal / dilution analysis

Every metric in sections 15-16 is computed **separately at 1%, 0.1% and 0.01%** and at TF0.
Pooling across levels is forbidden.

The 0.01% level is expected to fail in every arm. It is retained and reported because a
protocol that reports only the levels where the treatment can win is not a benchmark. If B1
produces a detection at 0.01%, that is a result requiring explanation, not a success to bank —
prior work established the level is signal-limited, so a detection there is first a suspicion
of a defect.

## 20. Success criteria

Preregistered. Fixed before any number in this benchmark exists.

```text
S1 (PRIMARY)
    zlo_min(B1) - zlo_min(B0) > 0   at 0.1%,   on BOTH individuals
AND zlo_min(B1) > zlo_min(C1)       at 0.1%,   on BOTH individuals
AND zlo_min(B1) > zlo_min(C2)       at 0.1%,   on BOTH individuals

S2 (NO REGRESSION)
    No level detected by B0 under the frozen replicate rule becomes undetected under B1,
    on either individual.

S3 (NO FALSE DETECTION)
    Scoring each TF0 replicate against the mean of the other two blanks, B1 produces no
    detection (z >= 3) on any blank replicate of either individual.

H1 is supported only if S1, S2 and S3 all hold.
```

Partial outcomes are named in advance and may not be relabelled:

```text
S1 holds on HCC1395 only          -> NOT REPLICATED (consistent with FIND-0021's
                                     individual-dependence; not a success)
S1 fails against C1               -> REFUTED: the gain is filter aggressiveness, not methylation
S1 fails against C2               -> REFUTED: the gain is filter architecture, not modification calls
S2 fails                          -> B1 is not admissible regardless of S1
S3 fails                          -> B1 is not admissible regardless of S1
```

## 21. Failure criteria

```text
F1  zlo_min(B1) <= zlo_min(B0) on either individual -> H1 not supported. Recorded as measured.
F2  C1 >= B1 on either individual                   -> H1 refuted by the retention control.
F3  C2 >= B1 on either individual                   -> H1 refuted by the shuffle control.
F4  S1 holds on one individual only                 -> NOT REPLICATED.
F5  B1 detects a blank (S3 fails)                   -> B1 inadmissible.
```

Any of F1-F5 is a valid, publishable benchmark outcome and must be preserved verbatim.
None of them may be re-described as partial success.

## 23. Execution constraints

- 24 BAM passes; one pass per sample yields all four arms (C1 and C2 are computed from the
  same in-memory per-read scores — no extra I/O).
- Prior equivalent runs: ~12 minutes per BAM on this host. Parallelise at most 14 concurrently.
- 112 cores, 503 GB RAM, no GPU. `/big8_disk` has 1.8 TB free; outputs are small TSVs.
- Source BAMs are read-only and on other users' volumes; nothing may be written there.
- `pysam 0.24.0`, `numpy 2.2.6`, `scipy 1.15.3`, Python 3.10.

## 24. Known limitations

1. Two individuals, both cell lines, no plasma. Nothing here speaks to cfDNA fragmentomics.
2. HCC1395's frame is chr1 only; COLO829's is genome-wide. Magnitudes are not comparable
   across individuals and no criterion compares them.
3. Replicates are subsamples of one library. The blank interval is built on pseudo-replicates
   whose spread is known to understate between-library spread by more than 10x (EV-0038).
   The interval is therefore optimistic **for both arms equally**.
4. HCC1395 is in the ClairS-TO `ssrs` training set and COLO829 is not; a difference between
   individuals may track training membership rather than biology.
5. HCC1395's methylation result (FIND-0021) is a within-individual figure that already failed
   to replicate at full magnitude on COLO829 (AUC 0.91 vs 0.72) at the *read-classification*
   task. The detection task has never been run on COLO829.
6. The oracle-free consensus requires the sample to be overwhelmingly normal. At 1% it is
   still >= 99% normal, but the premise weakens as tumour fraction rises and fails outside
   the MRD regime. This is a stated regime limit, not a measured one.
7. No limit of blank or limit of detection is claimed.

## 25. Unresolved decisions

```text
U1:
Question: The consensus in step 3 is built from reads overlapping candidates in the sample
          under test. At 1% tumour fraction, does the tumour contribute enough reads to
          contaminate its own reference?
Why it matters: If yes, B1's premise weakens at the highest level and the 1% row must be
          read with that caveat.
Required evidence: The tumour contributes ~1 read in 100 at 1%; the consensus requires
          MIN_COV=10 observations per position, so a position's rate moves by at most ~0.1
          from tumour reads. That is inside the 0.1/0.9 confident band's margin.
Must resolve before execution: NO — it is a stated caveat on the 1% row, and 1% is not the
          primary level.

U2:
Question: Does the unscorable-ALT fraction differ between blank and 0.1%?
Why it matters: If it does, missingness itself carries label information.
Required evidence: Measured and reported by this benchmark (section 22). C1 controls the
          retention component regardless of the answer.
Must resolve before execution: NO — it is an output of the benchmark, and the control that
          neutralises it is already in the design.
```
