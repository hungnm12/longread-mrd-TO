A grep of the source for unimodal, single modality, alone, each data type returned nothing. The 10⁻⁴ figure belongs to the three signals combined, and no one knows which axis contributes what.

Bounds on this project

"Dilute to 0.001% and still get a call" — the paper already ran that experiment, and it failed

A unit check settled it before any argument: 0.001% = 1×10⁻⁵, while SIMMA's LOD is 100 ppm = 1×10⁻⁴ = 0.01%. The ask was ten times below the reported limit.

Ceiling 1 — counting statistics
At 10⁻⁴ roughly 42 independent features suffice to hold the z-score. At 10⁻⁵ you would need about 4,200 — and only tens of independent copy-number segments exist. The features run out before the arithmetic does.
Ceiling 2 — the biological floor
Healthy-person variation in copy number, methylation and fragment length is 3–4 orders of magnitude larger than a 10⁻⁵ tumour signal. These are distribution-shift signals, so they sit in an already-salty pool.
Takeaway: to reach 10⁻⁵ you must change evidence type — to SNV (personalised, tumour-informed) or an SV/ecDNA junction, where the background is zero. At exactly 10⁻⁴ all you get is a scalar tumour fraction with an interval; SCNA, ecDNA and SNV are each already dead at that level.

Two of the four signals transfer — and both are already on disk

The deck's closing slide, and the same verdict reached independently in the paper-reading thread. Written in plain language on purpose, per the note: "dùng từ ngữ phổ thông hơn".

Copy numberYES — freeThe tumour line has an abnormal genome, and every dilution is that tumour mixed into its own normal cells, so the copy-number signal grows with the amount of tumour
MethylationYES — freeThe marks are already stored inside the files we have. Reading them costs nothing and needs no new sequencing — which holds only because the WGS branch is PCR-free; PCR would have erased them
FragmentomicsNOOur DNA came from cells grown in a dish, not from blood. Fragment lengths here reflect how the library was made, not the biology
SV / ecDNANOT YET
new work		No ecDNA is known in this cell line and we have never looked. Doable, but new work rather than a re-analysis — and the real barrier in cfDNA is tumour fraction, not read length, since cfDNA arrives at ~167 bp regardless
The design trap named while checking the dilution question
Diluting every point into one shared control pool erases inter-individual variance and produces an artificially optimistic LOD. The fix is a paired dilution series — the same control at every point, versus a different control at every point — which measures the false-optimism gap directly. Not drafted.
Takeaway: this is the same conclusion the 2026-08-31 signal inventory reached in private — today it became a slide that can be presented, with the reason for each verdict written in words a non-specialist can check.
