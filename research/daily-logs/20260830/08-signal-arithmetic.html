Operating point

"Which signal detects tumour better?" is not a question yet — it is an arithmetic problem first

The question assumes SNV, methylation, phasing, CNV and SV lie on one comparability axis. That premise was not accepted. Everything here is a function of TF and coverage, so the operating point was fixed first: HCC1395 dilution, 25x, TF = 1e-4, with the TF0 blank as control.

Question 1, issued — no computing required
For each of the five signals, write down two numbers on paper:
  • the expected value of that statistic at TF0 (blank)
  • the expected value of it at TF = 1e-4

If the two do not separate, that signal is dead by arithmetic — not because the right tool has not been picked yet.

Failing to write a number down is also an answer: it means "better" is still an intuition, not yet a quantity.
