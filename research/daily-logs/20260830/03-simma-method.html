SIMMA method

One library prep, split in two — four signals out of a single WGS run

Precision matters here: "multimodal from one sample" is one prep then split into two aliquots, not a single aliquot, and the targeted branch still uses PCR. Everything below is the paper's own assertion.

Wet lab — one end-repair + A-tailing, then split
WGS branch: native barcode → pool 16–32 samples → adapter → nanopore. No PCR, so the original molecule and its base modifications survive.
Targeted branch (optional): PCR + 76-cancer-gene capture panel with UMIs.

Integration: 7 concatenated feature blocks (copy number, methylation at several scales, fragment length, end motif) → Random Forest → TF with a per-sample confidence interval (conformal prediction)
Two things not to write wrong: conformal prediction does not make the assay more sensitive — it only changes how the result is reported, and a wide interval means "do not trust this sample". And the tumour-agnostic path contains no SNV feature at all: all 7 blocks are copy number, methylation or fragment length.
